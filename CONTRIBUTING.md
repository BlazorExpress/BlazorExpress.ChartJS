# Contributing to BlazorExpress.ChartJS

Thank you for helping improve BlazorExpress.ChartJS. Bug reports, ideas and pull requests are all welcome.

## Reporting a bug or asking for a feature

Open an [issue](https://github.com/BlazorExpress/BlazorExpress.ChartJS/issues). For a bug, include the package version, the .NET version, the browser, the smallest chart configuration that shows the problem, and what you expected to happen.

## Making a change

1. Fork the repository and create a branch from `main`.
2. Make your change. Keep each pull request to one fix or feature.
3. Build the solution and run the tests:

   ```shell
   dotnet build BlazorExpress.ChartJS.slnx
   dotnet test BlazorExpress.ChartJS.slnx
   ```

4. Open a pull request against `main` and describe what changed and why.
